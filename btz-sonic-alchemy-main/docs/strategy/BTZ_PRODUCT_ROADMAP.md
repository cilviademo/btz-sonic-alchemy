# BTZ Sonic Alchemy — Product Roadmap

## 1. v1.0 Release (The "Target Lock" Launch)

The v1.0 release must be laser-focused on the core identity: intelligent saturation with Target Lock.

**Must Ship:**
- Target Lock Engine (LUFS, RMS, Spectral).
- 9 Saturation Models (with actual neural weights or high-quality mathematical approximations).
- TruePeak Limiter (verified 4x ISP).
- BS.1770 Loudness Meter.
- Ivory System UI (Simple & Advanced modes).
- 20 Factory Presets.
- macOS and Windows Installers.

**Should Wait:**
- LFOs and Modulation (hide from UI for v1.0 to avoid clutter).
- Mid/Side processing (hide from UI for v1.0).

## 2. v1.1 Enhancements (The "Pro Workflow" Update)

Released 3-6 months after v1.0 to maintain momentum.

**Features:**
- Sidechain Input (for dynamic saturation triggered by external sources).
- Vectorscope / Goniometer visualizer.
- HQ-on-Export mode.
- Typed value entry for all knobs.
- Resizable UI (drag corner to scale).

## 3. v1.2 Expansions (The "Ecosystem" Update)

**Features:**
- User IR Loading (for custom cabinet/room simulation).
- A/B/C/D comparison slots.
- Advanced preset browser with tagging and search.

## 4. Future Ecosystem Opportunities (v2.0+)

Instead of cramming more features into BTZ, spin them off into a suite of plugins that share the Ivory System aesthetic and Target Lock philosophy.

- **BTZ Modulator:** A dedicated rhythmic multi-effect plugin using the LFOs and envelope followers stripped from the original BTZ concept.
- **BTZ Space:** An intelligent reverb/delay that uses Target Lock to maintain exact wet/dry LUFS ratios regardless of decay time.
- **BTZ Dynamics:** A dedicated mastering compressor/limiter suite.
